# Java Banking System

A banking system simulation built with Java to practice Object-Oriented Programming (OOP).

## Features

- Check account balance.
- Check overdraft limit.
- Deposit money.
- Withdraw money.
- Pay bills.
- Check whether the account is using the overdraft limit.
- Calculate the overdraft limit based on the initial deposit.
- Simulate a 20% fee on the overdraft amount used.

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Scanner for user input
- Switch statements and loops

## Project Structure

- `Main.java` — User interaction and banking menu.
- `classes/Count.java` — Account data and banking operations.

## Purpose

This project was developed to practice Java fundamentals, logical reasoning, classes, objects, constructors, methods, conditionals, and loops.
